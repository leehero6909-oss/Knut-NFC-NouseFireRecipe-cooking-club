# NFC — No use Fire Recipe

대학 요리 동아리 NFC의 정적 홈페이지 초안입니다.

## 파일 구성
- `index.html` : 홈페이지 콘텐츠와 섹션
- `style.css` : 반응형 디자인 및 스타일
- `script.js` : 모바일 메뉴 동작

## GitHub Pages 무료 배포
1. GitHub 계정에 로그인합니다.
2. 새 Repository를 만듭니다. 예: `nfc-cooking-club`
3. 이 폴더 안의 파일 4개를 저장소 최상위(root)에 업로드합니다.
4. 저장소의 **Settings → Pages**로 이동합니다.
5. **Build and deployment → Deploy from a branch**를 선택합니다.
6. Branch는 `main`, 폴더는 `/ (root)`를 선택하고 Save를 누릅니다.
7. 잠시 후 `https://사용자이름.github.io/nfc-cooking-club/` 주소로 접속합니다.

## 런칭 전 수정할 항목
- `index.html`의 Google Forms 링크를 실제 가입 신청 폼 주소로 교체
- 동아리의 실제 활동 사진, 운영진 소개, 학교 정보 추가
- 모집 일정과 문의 채널 추가
- 레시피/활동 게시물을 실제 콘텐츠로 교체

## 참고
현재 가입 신청 버튼은 Google Forms 기본 주소로 연결되는 임시 링크입니다.
회원 정보 저장, 로그인, 게시물 등록 기능은 아직 구현되어 있지 않습니다.
사진은 Unsplash 외부 이미지 주소를 사용하므로 인터넷 연결이 필요합니다.
